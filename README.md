# HeySis for Android — APK

HeySis for Android phones without Google Play, such as most Huawei phones.
If your phone has Google Play, install HeySis from
[Google Play](https://play.google.com/store/apps/details?id=app.heysis.cycle)
instead: updates arrive on their own.

**Download:** [HeySis.apk](https://github.com/WantbeFree/heysis-apk/releases/latest/download/HeySis.apk)
(latest version, Android 12 or newer). Each release lists its SHA-256.

How to install, and what works without Google services:
https://heysiss.vercel.app/huawei
